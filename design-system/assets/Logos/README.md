# Logos

The TASC logo exactly as exported from the website Figma file. `tasc-logo.svg` (teal letters, gradient A) goes on white and light grey. `tasc-logo-white.svg` (white letters, gradient A) goes on the dark footer and dark sections. `tasc-mark.svg` is the gradient A alone, for the favicon and small spaces. Header height is 36px. Do not recolour, stretch or redraw the mark. TCS pages use the same TASC logo.
